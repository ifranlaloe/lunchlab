# AGENTS.md

This repository contains Slidev decks for LunchLab sessions. The C4 deck lives in `slides.md`; additional decks use their own root Markdown entry.

## Working norms
- Keep deck content practical and facilitation-oriented.
- Prefer conceptual consistency across a deck over adding many disconnected examples.
- When updating session guidance, reflect changes in the session README and keep language concise.
- Keep key audience framing consistent when it becomes a session focus pivot.
- Keep the slide order and matching session README in sync when editing any deck.
- Put presentation assets in `public/assets/` and reference them with `/assets/...` paths.

## Session-specific guidance
- Keep `AGENTS.md` focused on repository-wide rules.
- For session-specific teaching concepts, workshop flows, and facilitation guardrails, use the README inside that session folder.

  - LunchLab #2: `zooming-with-c4/README.md`
  - Current Level 1 audience focus: travelers split by road, water, air, and railway.
  - Resource Scaling: `resource-scaling/README.md`
